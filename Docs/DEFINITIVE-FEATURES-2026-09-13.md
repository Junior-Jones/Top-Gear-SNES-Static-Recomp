# Definitive Edition changes — 13 September 2026

Historical baseline before version 2.0.0. For current Career qualification, passwords and the root heading, see CAREER-2.0.0.md and the cumulative VERSION.txt.

Career, one-player mode, replaces the lower view with five ranked native racers. The native records occupy $0212 through $0379, in 18-byte records: identity/visual flags +0, world position +7, lap +9, speed +10. $0204 and $0206 identify the two player slots. CPU names use ROM $0D:C47B and the native ID-minus-two mapping; CPU slot 1 uses COMPUTER. Ten distance checkpoints per lap record each car's crossing time at the native 60 Hz timer. Gaps compare the same checkpoint for both cars; unavailable or newly inverted gaps display dashes. Leader last-lap time is blank on lap one. Finished cars retain their native finish order and final lap timing. The display is restricted to live one-player Career; two-player Career and Rally retain their original lower view. Car-colour labels are omitted because a verified per-racer colour mapping is not yet established.

Time Trial starts at native pole ($1F00 = 19 before grid initialization). Rival entries are excluded from the native player render list, and the rival collision branch is bypassed. Native internal race records remain for the original completion bookkeeping. Position display remains first in solo mode. The lower timer displays zero until the initial start-line crossing rather than counting the pre-start countdown.

A naturally completed race exposed a Retry stack bug. Results entered Options by JMP at $0F:84AC; Options Start then attempted RTS at $0F:9294 without a corresponding JSR. The post-results context now resumes $0F:818E, the original next-race/pre-race path, without popping a nonexistent return address. The flag resets per Start and is set anew per completion. There is no retry-count limit.

Rally Selected Tracks uses a deadline of 300 emulated frames (under five seconds at native NTSC rate), not a number of menu polls. The initial held-Start release loop no longer suspends the deadline. Releasing then pressing can skip earlier. The original pre-race screen follows.

Rally's final-results return also marks the post-results menu context, so starting another event follows the corrected native pre-race route without popping an absent return address. A focused test checks both compiled dispatch paths and unchanged stack position.

Music stays at level five outside the title. Mute affects music. Native racing SFX and the private ninth-channel cues bypass music attenuation. Title music remains full volume when unmuted.

Settings adds Music Player with all 20 tracks. Highlighting starts the selected song (initially TG Title); Left/Right wraps through the catalog, A stops/resumes. R retains title-track cycling, also selecting the corresponding title in Music Player. Leaving the row restores normal title/menu music. Browsing does not consume Career, Rally or Time Trial shuffle state. TG2/TG3000 continue using their existing isolated engines. Original TG preview uses another instance of the same fail-closed AOT code and project DSP, namespaced at compile time; ROM-authoritative native upload-port transcripts initialize seven cached song starts. It does not replace the live game APU or private cue context. No prerecorded PCM, generic SPC interpreter or host player was introduced.

Catalog: TG Title, Frankfurt, Bordeaux, Hiroshima, Las Vegas, Qualified, Ending Theme; TG2 Title, Auckland, Ayers Rock, Canterbury Plains, Qualified, Ending Theme; TG3000 Title, Main Theme 1–4, Results, Ending Theme. The TG3000 labels match the original rip/tagger catalog: https://snesmusic.org/v2/profile.php?profile=set&selected=3063 . TG2 gameplay titles are also listed on the credited soundtrack release: https://music.amazon.com/albums/B08P9CL37Y . The names and mapping were cross-checked against the local approved music research.

The root OPTIONS screen keeps Career, Rally, Time Trial and Settings, and adds DEFINITIVE EDITION in its previously empty lower area.

Launcher adds Profile immediately after Audio, in both toolbar and Settings menu. Profile remains enabled before and during ROM execution. Mode selects shared Career/Rally P1 or independent Time Trial P1. Name accepts eight letters/digits/spaces and is stored in the game's uppercase format; four cars, Automatic/Manual, and four native control schemes are supported. Read-only SNES button descriptions update with the scheme and have no Tab stop. Save writes Data/player-settings.dat atomically and preserves the other bank, player 2 and music flags. When a game is loaded, Save asks whether to reset now. Yes returns the core to its cold-reset title sequence and imports the setup; No keeps the current game running and applies it at the next reset. The app falls back to the canonical profile record when the remodeled-menu export is unavailable, and its synchronized cache prevents a pending gameplay save from overwriting the Profile change. The existing music-state.dat and time-trial.dat formats remain unchanged. No code is stored in Data.

Headless verification includes a hidden native Profile dialog test, all 20 Music Player tracks with audio energy checks, playlist isolation, all four profile/control mappings with reloads, Rally deadline while Start is held, Career screenshots/telemetry, and natural Time Trial races. The journey harness accepts --runs=N for repeated completed races, verifies the requested course/car/gearbox at every handoff, saves every result, captures delayed results/Retry/Top5 screens and waits 90 frames before the final Time Trial menu screenshot. Default is two runs. Las Vegas completed twice through Retry; Los Angeles completed three times through two successive Retries. Final regression totals and receipts are recorded separately.

The retry harness accepts a completed run outside the Top 5 when all five saved entries outrank it, while still requiring an exact durable last-run record. Report rank zero means outside the Top 5.
