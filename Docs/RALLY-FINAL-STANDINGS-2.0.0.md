# Rally qualification and final standings - 2.0.0

Rally has no continues. For event tracks 1 through 7 the player must finish in the top 8, 7, 6, 5, 4, 3 and 2 respectively. Every active human must qualify in two-player mode; a solo CPU result cannot substitute for P1. Failure uses the original failure background, then returns to the main menu with Rally selected. No Yes/No retry selector is shown.

Track 8 has no finishing-position requirement, including for either human in two-player mode. Its race results award the original position-based points, then the native standings sort the cumulative points from all eight races. The highest points total leads the final standings, regardless of who won the final race. The final tally is shown before returning to the main menu. Equal points retain the native stable standings order; no new tiebreak or final-race-winner override is introduced. Starting a new Rally clears the event points.

Both early post-race classification and the later native qualification rendezvous use the new Rally rule. The last-race bypass occurs before looking for a cutoff finisher, so a low position or a racer outside the counted finishers cannot trigger a continue/failure gate in the finale. Terminal Rally failure uses the existing terminal presentation route; Career's three continues and Time Trial's unlimited Retry retain their own behavior. The shared solo Top 5 panel, CPU audio filter, music playlist and Data schemas are unchanged.

The headless rule matrices test every finishing position, all seven thresholds and the ungated finale, including both humans and all scheduled course IDs. The event test navigates the Rally menus, injects a ninth-place finish on race 1 to verify terminal failure/no continues, then runs eight native race-result transitions while independently summing the ROM points table. It verifies all twenty cumulative totals at every stage and descending final order. P1 wins the first seven test races and finishes third in race 8, then remains first by cumulative points. Finish-order injection is controlled test data, not a claim of naturally driven races. Screenshots capture the final tally and menu return. Career continue regression verifies its existing budget and exact-track retries remain functional. No Data format changes or automated times are installed in the user copy.

Their fourteen code bytes are protected in the static bitmap; every opcode implementation was already emitted. Docs/generated/TG2-NOTE-OFF-AUTHORITY.json records the source hash and decoded bytes. No generic interpreter, runtime decoding, music replacement or voice-9 modification is introduced.

All opcodes were already emitted; no generic instruction cases were added. TG2-SEQUENCE-COMMAND-AUTHORITY.json records all static byte spans.
