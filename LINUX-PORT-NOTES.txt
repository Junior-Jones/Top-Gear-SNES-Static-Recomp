Top Gear SNES Static Recomp 1.2.0 - Linux qualification port
Prepared 2026-09-04

Scope
-----
This port preserves the static core and ports the build/test boundary to Linux.
The production Win32 GUI/DirectSound launcher remains Windows-specific; the Linux
qualification application is the existing platform-neutral headless frontend.
No static-core execution semantics were changed for the port.

Linux changes
-------------
- Top-level CMake no longer rejects non-Windows hosts.
- Win32 launcher/DirectSound/settings/SDL gamepad targets are built only on Windows.
- Portable audio-resampler test remains enabled on Linux.
- Renderer-instance test uses pthreads/sched_yield on Linux and retains Win32 threads on Windows.
- GCC-only -Wno-class-memaccess is now correctly limited to GNU C++.
- Source/integrity manifests were regenerated for this Linux-port source tree.

Build example
-------------
cmake -S . -B build -DBUILD_TESTING=ON -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_C_FLAGS_RELEASE="-O1 -DNDEBUG" \
  -DCMAKE_CXX_FLAGS_RELEASE="-O1 -DNDEBUG" \
  -DTOPGEAR_TEST_ROM="/path/to/Top Gear (USA).sfc"
cmake --build build -j4
ctest --test-dir build --output-on-failure
